## What I did

**toyraft `rc.3 → v1.0.0` bump + workaround retirement** (`c360e8e`).
Bumped `go.mod`/`go.sum` and consumed the new API surface, deleting each
dogfood workaround:
- FRICTION-05 → `raft.IsNotLeader(err)`: `Broker.NotLeaderHint` delegates the
  redirect classification to the predicate; the hand-rolled 3-error match is gone.
- FRICTION-06 → `raft.Node.NodeID()`: `selfID` field + the `AttachRaft(node,
  selfID)` param dropped; self is excluded from `MatchIndex` via `b.raft.NodeID()`.
- FRICTION-07 → `raft.Node.NotifyC()`: `waitForReplication` blocks on the
  coalescing progress signal; the 5ms poll ticker is gone.

Behaviour unchanged; `go build ./...` + `go test ./... -race` green, `WAIT`
suite green on `-race`.

**Public-bind guard** (`3050556`). The toyraft peer transport is
unauthenticated/plaintext (trusted-network threat model). `config.validate()`
now refuses a public/wildcard raft bind — `isPublicBind` rejects an
empty/wildcard host (`0.0.0.0`, `::`) or a non-loopback/non-private literal IP;
a non-IP hostname is left to the operator. Escape hatch:
`--raft-allow-public-bind`. Mirrors the redis protected-mode posture without
adding auth to the raft plane (v4). Recorded as the ADR 0030 addendum.

**Bench cluster mode** (`6a359fe`). `toymq-bench --peers` drives load through a
redirect-following `client.ClusterClient` so the replicated path can be
measured against standalone. A `publisher` interface abstracts `*client.Client`
and `*client.ClusterClient`, so the producer loop measures either mode with no
branching; the report labels the run.

**Packaging** (`5aade8f`). goreleaser `dockers`/`docker_manifests` build one
multi-arch OCI image (linux amd64+arm64) to `ghcr.io` — cluster role is a
runtime flag, not a build-time distinction — plus `Dockerfile.goreleaser` and
`docker-compose.cluster.yml` for a local 3-node cluster (binds `0.0.0.0:7000`
inside the private compose network with `--raft-allow-public-bind`, the one
intended override).

**Docs + benchmark** (`a206de0`). README cluster quickstart + Replication cost
section. Standalone vs replicated 3-node on matched load (4 producers × 2000 ×
256B, tmpfs): 26,392 → 2,485 msg/s. **Consensus tax** ~10.6× throughput drop;
p50 ~11.4× / p95 ~9.7× / p99 ~6.5×. The tail gap narrows because standalone p99
already carries fsync/scheduling jitter. Cross-referenced from toykv's
BENCHMARKS.md (ToyMQ ~1.8× toykv on matched load; the "~100×" figure is the
toyraft rc.3→v1.0.0 flush-on-`Propose` fix, not replicated-vs-standalone).

**Release finalization** (`feat/release-v3-finalize`). Promoted the CHANGELOG
`v3.0.0` draft to a released `[3.0.0] — 2026-09-19` section; marked v3 M6 done
in ROADMAP; hardened `release.yml` for multi-arch OCI publish (qemu + buildx +
ghcr login + `packages: write`) so the goreleaser docker stanzas actually push
on tag. Tagged `v3.0.0`.
